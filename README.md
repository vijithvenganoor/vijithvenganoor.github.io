## Quick Deployment to GitHub Pages
```bash
git init
git add index.html assets/ README.md .nojekyll
git commit -m "Launch Vijith V.S 3D Interactive Nexus Portfolio"
git branch -M main
git remote add origin https://github.com/vijithvenganoor/portfolio.git
git push -u origin main
```
Then go to **Repository Settings → Pages → Source: Deploy from a branch (`main` / `/root`)**.
